Process
How Semantic DNA Search Works

Three steps from raw text to explainable results — entirely inside PostgreSQL.

1

Extract Genome

Every document is tokenized into 3-word sliding windows. Each window becomes a 5-dimensional gene encoding its structure, sound, grammar, depth, and rarity.

2

GIN Pre-Filter

PostgreSQL's GIN index narrows millions of documents to ~500 candidates using trigram hash containment queries — no full table scan needed.

3

Score & Rank

Each candidate is scored across all 5 dimensions with configurable weights. Results are fully explainable — you see exactly why each document matched.

The Genome
5-Dimensional Semantic Encoding

Each 3-word window is encoded along five independent axes. Together they form a fingerprint no embedding can replicate.

🔢

Trigram Hash

MD5 of each 3-word window. Captures exact phrase matches and preserves word order.

40% weight
🔊

Phonetic Code

Vowel-stripped, consonant-normalized sound skeleton. Matches despite typos and misspellings.

20% weight
📐

POS Sequence

spaCy grammatical tags per window. Finds docs with the same sentence structure across different vocabularies.

20% weight
📊

Context Depth

L1–L4 specificity scale. Separates function words from jargon. Matches expert content to expert queries.

10% weight
📈

Entropy Score

IDF-based rarity scoring. Rare domain-specific terms outweigh common filler words automatically.

10% weight
